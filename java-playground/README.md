# 구현 기능
- 각 자동차에 이름을 부여할 수 있다. 
  - 예외) 자동차 이름은 5자를 초과할 수 없다.
- 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.
- 자동차 이름은 쉼표(,)를 기준으로 구분한다.
- 전진하는 조건은 0에서 9 사이에서 random 값을 구한 후 random 값이 4이상일 경우이다.
- 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다. 우승자는 한명 이상일 수 있다.
---

## 입력
- 자동차 이름 부여
  - 쉼표를 기준으로 구분하여 부여
- 시도할 횟수 부여

## 출력
- 자동차 이름함께 전진하는 자동차 출력
- 시도 횟수

## 자동차
- 이름을 가진다.
  - 이름이 5자 초과하면 예외
- 속도? 거리?를 가진다.
- 전진 조건을 가진다.
  - 0에서 9사이의 랜덤 값이 4이상이면 전진
  
## 유틸/컨버터
- 랜덤 숫자 만들기
- 쉼표 기준 자르기
